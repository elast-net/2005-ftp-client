## FTP Client (C, 2005)
A minimal FTP client written during university studies, implementing 
core FTP commands (USER, PASS, LIST, RETR, CWD, MKD, etc.) directly 
over TCP sockets, including manual parsing of PASV mode responses.

Included as an early example of protocol-level thinking — written 
years before my professional focus shifted toward higher-level API 
integrations and automation.
